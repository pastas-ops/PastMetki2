# PastMetki — стартовый проект

Это переработка исходного приложения Zametki в адаптивное веб-приложение/PWA с Supabase. Интерфейс можно установить на телефон и компьютер из браузера. Исходная Tkinter-версия не удаляется: этот проект лежит отдельно.

## Что уже реализовано в этом MVP

- Регистрация и вход по логину и паролю (без ввода email пользователем).
- Личные заметки с пунктами и дедлайнами.
- Отметка пунктов, перенос заметки в историю, восстановление и очистка истории.
- Календарь дедлайнов.
- Поиск друга по логину или коду приглашения, совместные чаты, очистка истории чата.
- Профиль, смена имени/логина с подтверждением текущим паролем, аватар.
- Светлая/тёмная жёлто-чёрная темы, адаптивная навигация, CSS-анимации.
- PWA manifest и service worker для установки приложения.

## 1. Создай проект Supabase

1. Открой https://supabase.com/dashboard и создай проект.
2. В SQL Editor выполни целиком `supabase.sql`.
3. В Authentication → Providers → Email отключи **Confirm email**. Это необходимо, потому что пользователь входит по логину, а не по адресу почты.
4. В Project Settings → API скопируй Project URL и `anon` / publishable key.
5. В `config.js` замени `YOUR-PROJECT` и `YOUR_SUPABASE_ANON_PUBLIC_KEY`.

**Важно о логине:** Supabase Auth нативно использует email/пароль. Чтобы интерфейс мог принимать только логин, приложение формирует внутренний адрес вида `логин@login.pastmetki.invalid`. Пользователь его не вводит. Это MVP-решение без восстановления пароля по email. Для публичного запуска рекомендовано добавить Edge Function для регистрации/входа по username, защиту от перебора и безопасный сценарий восстановления доступа.

## 2. Запуск локально

Нужен Python 3 (у тебя он уже использовался для старой версии):

```bash
cd PastMetki
python -m http.server 8080
```

Открой http://localhost:8080. Не открывай `index.html` двойным кликом: для Supabase и service worker нужен локальный веб-сервер.

## 3. Публикация

Размести папку на HTTPS-хостинге: например, Supabase Hosting не предоставляет статический хостинг, подойдут Netlify, Vercel или Cloudflare Pages. Загрузи все файлы проекта в корень сайта. В Supabase Authentication → URL Configuration добавь домен сайта в Site URL и Redirect URLs.

## 4. Установка как приложение

- Android/Chrome: меню браузера → «Установить приложение» / «Добавить на главный экран».
- iPhone/Safari: Поделиться → «На экран Домой».
- Windows/Chrome или Edge: значок установки в адресной строке или меню браузера.

Это устанавливаемая PWA. **Нативные системные виджеты** рабочего стола Windows, Android и iOS не входят в этот веб-MVP: для них нужны отдельные native-компоненты/оболочки для каждой ОС.

## Безопасность и ограничения текущего MVP

- В браузере используется только публичный anon/publishable key; никогда не вставляй `service_role`.
- Таблицы защищены RLS-политиками. Пользователь может менять только свои заметки; сообщения доступны участникам диалога.
- Поиск профилей для добавления друзей в MVP открыт авторизованным пользователям по username/invite code. Перед публичным запуском лучше добавить запросы в друзья с подтверждением и rate limiting.
- Очистка чата удаляет сообщения для обоих участников.
- Реалтайм-подписка пока не подключена: новые сообщения загружаются после отправки/повторного открытия чата. Для мгновенной синхронизации нужно включить Supabase Realtime и добавить подписку.
- Для смены логина сейчас профиль обновляется в таблице; внутренний email Supabase Auth остаётся прежним. Вход по новому логину требует синхронизации auth identity через Edge Function. Поэтому смена логина отображена в интерфейсе, но полноценная смена credentials требует следующего серверного шага.
- Заметки старой версии хранятся в `reminders_data.json`. Автоматический импорт из локального JSON пока не подключён; это можно сделать отдельным мигратором, чтобы не потерять старые записи.

## Структура

- `index.html` — страницы и компоненты интерфейса.
- `styles.css` — темы, адаптивная сетка и анимации.
- `app.js` — логика интерфейса и запросы Supabase.
- `config.js` — публичные параметры Supabase.
- `supabase.sql` — таблицы, индексы, триггеры, RLS и storage.
- `manifest.webmanifest`, `sw.js` — установка и кеширование PWA.

## 5. APK и EXE через GitHub

В проект добавлены GitHub Actions для сборки Android APK и Windows EXE. Инструкция находится в `BUILD-APK-EXE-RU.md`. Перед запуском сборки заполни `config.js` параметрами Supabase.
